# Stitch Luxury Car Showcase

A premium automotive design showcase featuring three luxury car-inspired landing pages built with static HTML and Tailwind CSS.

## Included pages

- `stitch_luxury_car_showcase/aether_carbon/` — design system and brand concept
- `stitch_luxury_car_showcase/car_details_2025_elite/` — vehicle detail landing page
- `stitch_luxury_car_showcase/homepage_drive_the_future/` — futuristic homepage concept

## How to view locally

Open the HTML files directly in a browser, or run a simple local static server from this project root:

```bash
python -m http.server 8000
```

Then visit:

- http://localhost:8000/stitch_luxury_car_showcase/homepage_drive_the_future/code.html
- http://localhost:8000/stitch_luxury_car_showcase/car_details_2025_elite/code.html

## Design direction

The project follows a dark luxury aesthetic with:

- obsidian and midnight surfaces
- electric cyan highlights
- glassmorphism panels
- editorial automotive typography
- responsive premium landing-page layouts

## Notes

This is a front-end concept project and is intended for design exploration, portfolio presentation, and static preview use.
